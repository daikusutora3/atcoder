数値演算は、特記がなければ定数時間として計算量を記載します。関数・クラス・メソッドの docstring でも計算量を確認できます。クラスには構築と主要操作の計算量をまとめています。

## 使い方

1. カテゴリの目次から用途に合うライブラリを選ぶ。
2. 説明の `Summary`・`Functions` または `Snippet` で、入力前提・API・計算量を確認する。
3. `Usage` を参考に、コードを解答へコピーして使う。スニペットは説明内のコードを使う。

docstring の URL は、トップレベル関数・クラスごとに `Source: https://github.com/daikusutora3/atcoder` を1つだけ記載します。コード内に `Docs:` は記載せず、使い方は目次から同名 Markdown を参照します。個別ファイルやコミット ID を出典として指定する必要はありません。クラスに URL がある場合、内部メソッドへの重複記載は省きます。

コンテストで使う AI 作成コードは開始前に公開リポジトリへ push し、提出へコピーするときに `Source:` を残してください。複数のライブラリを使う場合、提出コード全体に次のコメントを一度記載する運用でも構いません。メソッドだけを切り出す場合も、この出典を残してください。

```python
# Source: https://github.com/daikusutora3/atcoder
```

実装変更後にコミット ID を埋め直す手順は不要です。AtCoder への事前提出は行いません。この運用は、リポジトリのトップ URL でよいというユーザー提示の運営者の回答に基づきます。事前公開と参照 URL の添付が必要なことは [公式規則](https://info.atcoder.jp/entry/llm-rules-ja) に従います。
