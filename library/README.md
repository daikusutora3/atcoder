# 競プロライブラリ

提出へコピーして使う Python の実装と、使い方・前提・計算量をまとめたメモです。

[リポジトリのトップ](../README.md)

## 用途から探す

| カテゴリ | 主な用途 |
| --- | --- |
| [グラフ](./graph/README.md) | 最大流・流量復元、最大二部マッチング、有向グラフの閉路、単一始点最短距離、トポロジカルソート |

## 使い方

1. カテゴリの目次から用途に合うライブラリを選ぶ。
2. 説明の `Summary`・`Functions` または `Snippet` で、入力前提・API・計算量を確認する。
3. `Usage` を参考に、コードを解答へコピーして使う。スニペットは説明内のコードを使う。

docstring の `Source:` はコード本体、`Docs:` は説明へのリンクです。どちらも公開済みの版の完全なコミット ID に固定します。クラスに URL がある場合、内部メソッドへの重複記載は省きます。

コンテストで使う AI 作成コードは開始前に Web 上へ公開し、提出へコピーするときに `Source:` を残してください。メソッドだけを切り出す場合は、その部分にも出典を付けてください。

実装変更時は変更版をコミットして公開し、その ID へ URL を更新します。実装公開と URL 更新は別コミットにします。古い版の URL を変更後の実装の出典に使わないでください。
